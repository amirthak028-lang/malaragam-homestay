# Malaragam Homestay Website

Responsive static website for Malaragam Homestay, Mayiladuthurai.

## Files
- `index.html` — website content and sections
- `styles.css` — responsive design
- `script.js` — mobile navigation, WhatsApp enquiry form and photo lightbox
- `assets/` — eight selected photographs

## Selected photographs
- 2 bedrooms
- 1 spacious hall
- 1 bathroom
- 1 warm-light photograph
- 1 parking photograph
- 1 traditional entrance photograph
- 1 kitchen photograph

Open `index.html` in a browser to preview. Keep the `assets` folder alongside it. Upload the complete folder to your hosting provider when publishing.
